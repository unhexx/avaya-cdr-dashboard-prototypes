# Aquarius CDR Dashboard Prototypes

Четыре UI-прототипа современного дашборда для анализа Call Detail Records (CDR) систем Avaya, выполненные в фирменном стиле **Aquarius**.

## Бренд Aquarius

Проект полностью соответствует официальному брендбуку Aquarius (aq.ru/about/brandbook):

- **Акцент (Лазурный лёд)**: `#28AFCA`
- **Базовый (Стальной фьорд)**: `#A2B7C8`
- **Тёмный (Северный лес)**: `#24566C`
- Пиксельный мотив
- Типографика: Inter (тело) + Aquarius (заголовки, fallback Inter)
- UI по умолчанию на русском языке

## Быстрый старт

```bash
cd frontend
npm install
npm run dev
```

Откройте http://localhost:5173
