## Пиксельный мотив

Пиксель — смысловое ядро визуального языка бренда с 2021 года. Использовать в логотипе, акцентах, loaders, borders, decorative elements. Символизирует цифровую точность и полный цикл (разработчик, производитель, вендор, сервис).

## Логотип

- Wordmark "Aquarius" + графический знак Q с акцентным пикселем (#28AFCA)
- Только оригинальная векторная версия
- Охранное поле 2x
- Варианты: полноцветный, инвертный (белый), в фирменных цветах, чёрный
- Запрещено: изменение пропорций, контур, старый логотип, эффекты, вращение

## Правила UI

- Русский язык — основной (i18n en опционально)
- Светлая / тёмная тема на базе палитры
- Все CSS variables, Tailwind theme, shadcn/ui компоненты маппятся строго на фирменные цвета
- Контраст WCAG 2.1 AA+
- Zero deviations от брендбука
